## 2. Ranked Fix List (Highest Impact First)

1. **[WPO + Usability] Optimize Images & Cut Page Weight Below 2 MB**
   - *Evidence:* `audit.txt` line 150 (`page weight ~6802 KB`), `home/report.json` line 52 (`mobile.vitals.lcpMs: 8532`).
   - *Issue:* Five full-resolution raw PNGs (`0263a98b...png` at 1.93 MB, `8001a072...png` at 1.85 MB, `2ec0a5ba...png` at 1.16 MB) inflate page weight to 6.8 MB, producing an unacceptable 8.5s mobile LCP on throttled connections.
   - *Fix:* Convert all PNG mockups to modern WebP/AVIF formats with responsive `srcset` (`sizes="(max-width: 768px) 100vw, 50vw"`), capping each asset under 150 KB. Add explicit `width` and `height` attributes to all `<img>` tags to eliminate layout shift warnings.

2. **[Content + Usability] Replace `/projects` Placeholder Stub with Real Case Study Archive**
   - *Evidence:* [`projects/d-01-hero.png`](file:///Users/kedarr/Documents/MyWork/Websites/Portfolio/.jury/kedar.figma.site/shots/projects/d-01-hero.png), `audit.txt` lines 139–140.
   - *Issue:* The primary navigation target `/projects` displays an under-development dead-end with a cat photo (*"Oops. This page is currently under development. Key projects listed on the homepage."*).
   - *Fix:* Remove the development banner. Build an archive grid presenting complete case studies with problem framing, methodology, role, and outcomes. Give the page a distinct title (`<title>Projects — Kedar Mulay</title>`) and canonical tag.

3. **[Design + Semantics] Design a Dedicated 404 Page in Site Voice with Recovery CTA**
   - *Evidence:* [`404/d-01-hero.png`](file:///Users/kedarr/Documents/MyWork/Websites/Portfolio/.jury/kedar.figma.site/shots/404/d-01-hero.png), `404/report.json` lines 17, 100–116, `audit.txt` line 143.
   - *Issue:* The 404 response paints an unstyled white browser page with raw `<pre>Not Found</pre>`, missing `<title>`, `<html lang="en">`, and `<h1>`.
   - *Fix:* Create a dark-themed 404 template (`background: #000; color: #fff`) matching the portfolio typography, featuring an `<h1>` heading ("404 — Lost in Speculation"), a descriptive message, and an interactive return button `<a href="/" class="btn">Return Home</a>`.

4. **[Animations/Transitions + Design] Upgrade Interactive Hovers & Custom Focus States**
   - *Evidence:* [`home/h-01-hover.png`](file:///Users/kedarr/Documents/MyWork/Websites/Portfolio/.jury/kedar.figma.site/shots/home/h-01-hover.png) through [`h-05`](file:///Users/kedarr/Documents/MyWork/Websites/Portfolio/.jury/kedar.figma.site/shots/home/h-05-hover.png), [`home/k-01-focus.png`](file:///Users/kedarr/Documents/MyWork/Websites/Portfolio/.jury/kedar.figma.site/shots/home/k-01-focus.png) through [`k-04`](file:///Users/kedarr/Documents/MyWork/Websites/Portfolio/.jury/kedar.figma.site/shots/home/k-04-focus.png).
   - *Issue:* Primary nav pills, CTAs, and arrow links only change text color from `#fd4747` to `#ffffff` (`report.json` `colorOnly: 1`), and keyboard focus falls back to default browser blue outlines.
   - *Fix:* Add tactile kinetic feedback: animate a subtle background pill flood on hover/active (`background: rgba(255,255,255,0.08); transform: translateY(-1px)`), and translate arrow links 3px diagonally (`transform: translate(3px, -3px)`). Style a cohesive custom focus ring: `outline: 2px solid #fd4747; outline-offset: 4px; border-radius: 6px;`.

5. **[Accessibility] Resolve WCAG AA Color Contrast Failures**
   - *Evidence:* `home/report.json` lines 213–223 (`color-contrast x6`), `projects/report.json` line 175.
   - *Issue:* Coral text `#fd4747` on `#404040` dark grey containers yields a 3.04:1 contrast ratio, failing the 4.5:1 WCAG AA minimum.
   - *Fix:* Lighten text to `#ff7878` or place `#ffffff` text on `#333333` badge backgrounds with a 1px `#fd4747` border to achieve > 4.8:1 contrast.

6. **[Responsive + Animations] Fix Mobile Nav Occlusion & Add Route Transitions**
   - *Evidence:* [`home/m-02-scroll.png`](file:///Users/kedarr/Documents/MyWork/Websites/Portfolio/.jury/kedar.figma.site/shots/home/m-02-scroll.png), [`m-03-scroll.png`](file:///Users/kedarr/Documents/MyWork/Websites/Portfolio/.jury/kedar.figma.site/shots/home/m-03-scroll.png), [`home/d-90-transition-a.png`](file:///Users/kedarr/Documents/MyWork/Websites/Portfolio/.jury/kedar.figma.site/shots/home/d-90-transition-a.png) to [`d-91`](file:///Users/kedarr/Documents/MyWork/Websites/Portfolio/.jury/kedar.figma.site/shots/home/d-91-after-nav.png).
   - *Issue:* The floating nav pill rests directly on top of card headlines on 390px screens. Page navigation between `/` and `/projects` is a raw hard cut.
   - *Fix:* Hide the mobile floating nav on scroll-down and reveal on scroll-up (`transform: translateY(-120%)` transition) or reposition to a thumb-friendly bottom dock. Implement View Transitions API (`::view-transition-old(root)`, `::view-transition-new(root)`) with a subtle 250ms crossfade.

7. **[Semantics/SEO] Implement Semantic `<h1>`, Unique Meta Titles, and Robots.txt**
   - *Evidence:* `home/report.json` line 29 (`h1: []`), `projects/report.json` line 25 (`h1: []`), `audit.txt` lines 1, 2, 144.
   - *Issue:* Neither page contains an `<h1>` element, both share duplicate `<title>Kedarr</title>`, meta description is 25 chars, and `robots.txt` is missing.
   - *Fix:* Add `<h1 class="sr-only">Kedar Mulay — UX & Speculative Designer</h1>` to the home hero. Expand meta description to 120–150 characters. Provide unique titles per page (`<title>Kedar Mulay — UX & Speculative Designer</title>` vs `<title>Projects — Kedar Mulay</title>`). Add `<link rel="canonical">` and a standard `/robots.txt`.
